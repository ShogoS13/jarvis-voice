shorts-uploader について

個人が自分のYouTubeチャンネルを運営するための、非公開の自動化ツールです。

このツールは何をするか

  • 運営者本人が作った短い動画（ショート動画）を、運営者本人のYouTubeチャンネルに、予約公開としてアップロードします（YouTube Data API の動画アップロードを使います）。
  • 運営者本人のチャンネルの、動画の一覧と、視聴回数などの統計を読み取り、次に作る動画の参考にします。
  • 運営者本人が管理する6つのチャンネルだけが対象です。他人のチャンネルや、他人の動画には、アクセスしません。

公開範囲

このツールは、一般には公開していません。運営者本人だけが、自分のパソコンと自動実行の環境で使います。ほかの利用者のアカウントでログインしたり、ほかの利用者のデータを集めたりしません。

データの扱い

くわしくは、プライバシーポリシーをご覧ください。
