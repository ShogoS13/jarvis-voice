プライバシーポリシー

shorts-uploader（個人が自分のYouTubeチャンネルを運営するための、非公開のツール）のプライバシーポリシーです。最終更新: 2026年10月13日

1. 集める情報

このツールが扱うのは、運営者本人のGoogleアカウントでログインして許可を受けた、運営者本人のYouTubeチャンネルの情報だけです。具体的には、チャンネルの識別情報、動画の一覧、視聴回数などの統計、アップロードする動画と、その題名・説明です。ほかの利用者の個人情報は、集めません。

2. 使いみち

集めた情報は、運営者本人の動画をアップロードすることと、運営者本人のチャンネルの動画の成績を確かめて、次の動画づくりの参考にすることだけに使います。広告、販売、分析サービスなどのために、第三者へ渡すことはありません。

3. 保管

ログインの許可（トークン）は、運営者本人が管理する非公開の場所（自分のパソコンと、非公開の自動実行の設定）にだけ保管します。公開される場所には、置きません。

4. 第三者への提供

YouTube API から得た情報を、第三者へ提供したり、販売したりしません。

5. 許可の取り消しとデータの削除

運営者本人は、Googleアカウントの「サードパーティのアクセス管理」から、いつでもこのツールの許可を取り消せます。取り消すと、このツールは、以後チャンネルの情報にアクセスできません。保管しているトークンは、運営者本人がいつでも削除できます。

6. 利用規約など

このツールは、YouTube 利用規約に従っています。また、YouTube API サービスを通じて得た情報の扱いには、Google プライバシー ポリシーが適用されます。

7. 連絡先

お問い合わせは、このページを公開しているGitHubのリポジトリ（ShogoS13/jarvis-voice）の Issues からお願いします。
