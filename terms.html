利用規約

shorts-uploader（個人が自分のYouTubeチャンネルを運営するための、非公開のツール）の利用規約です。最終更新: 2026年10月13日

1. このツールについて

このツールは、運営者本人だけが、自分のYouTubeチャンネルの運営のために使う、非公開のツールです。一般の利用者への提供や、公開はしていません。

2. 対象

対象は、運営者本人が管理する自分のYouTubeチャンネルだけです。他人のチャンネルや、他人のアカウントに、アクセスしたり、操作したりしません。

3. YouTube の規約の遵守

このツールの利用者は、YouTube 利用規約、YouTube API サービス利用規約、YouTube API サービス デベロッパー ポリシー、そして Google プライバシー ポリシーに従います。

4. 禁止する使い方

次のことは、しません。他人のデータを集めること。YouTube API から得た情報を、売ったり、第三者へ渡したりすること。視聴回数や登録者数を、不正に増やすこと。YouTube のしくみを妨げること。

5. 動画の内容

アップロードする動画は、運営者本人が企画・制作したものです。台本と映像の作成にはAIの支援を使いますが、公開する内容の責任は、運営者本人が負います。

6. 免責

このツールは、現状のまま使います。YouTube や Google のサービスの変更・停止などにより、予告なく使えなくなることがあります。

7. 変更

この規約は、必要に応じて変更します。変更後の内容は、このページに掲載します。

8. 連絡先

お問い合わせは、このページを公開しているGitHubのリポジトリ（ShogoS13/jarvis-voice）の Issues からお願いします。
